## 资格与口径

接纳文档化实幅态，不要求最大纠缠。公开总口是
`SaturationMonoid.PhysicsCore.Stage10.Bell.RealFamily.prediction`。
检验范围为实结构、Born 线性与由制备生成的 Δ/χ 形状及其仪器运输；不检验原 SpinPair
源必然产生该非最大纠缠态，也不借此复用原最大纠缠内容的经验身份。
原 source、root、tick16/17、r0002 锁和结果不改；不安装新 authority，不触发 U7/U8。

论文 Eq.(2) 的 HH/VV 制备和 Fig.2 控制在 `instrument.json` 冻定为设计输入。
角度相对于垂直偏振，故采用 V,H 基顺序，Bloch 轴为 (sin 2φ, cos 2φ)。
公开小数仅确定方向；以径向归一化生成 c,s，再生成 Δ=c²−s²、χ=2cs。
舍入误差不被宣称为实际制备误差上界；其覆盖必须由独立制备校准支付。

一手控制来源：[论文第4页](https://arxiv.org/pdf/1511.03189#page=4)。
它明确将最优设置联系到包含损失、背景和制备条件的装置仿真。
`checks.py` 验证全部单元与独立张量投影计算一致、镜像角度及 primed 破坏性结构，
并拒绝错误基顺序与 Bob 符号。**这不是完整装置最优性的证明。**
不得补一个任意损失值、偷用目标数据拟合或放宽容差，使“最优”门禁通过。
独立名义目标函数、信道输入及事先确定的舍入判据交付后，才可重跑该门禁。

## 完整试次与 no-click

点击记 +1，未点击确定性记 −1。不得丢弃双未点击、单点击或按 coincidence 留样。
先固定一个 sync 试次中的一个 pulse slot 和本地时间窗，之后不能按 test 选择窗口。
单透射端口的被阻挡输出没有第二只探测器，不能把它当作另一个高效率读出端口。
`real_family.loss_assignment` 先做 F0/F1 端口赋值，再按各端口 η 检测，再在未点击分支
加入独立背景；最后才执行确定性再赋值。NIST 固定 eta_minus=0，泄漏由赋值/模型误差负责。
单位双端口效率、无背景时，机具精确退化为原 F0/F1 核；这只是机具回归，不是 NIST 几何。

完整试次模型另含源对发生概率 q：q 倍的单对信道输出，加 (1−q) 倍的真空背景输出。
单对理想表不能当作所有 sync 的观测表。多对、死时间、脉冲合并及非独立噪声须有
单独的模型 TV 余项；本版没有把脉冲合并假设成独立单对事件。所有实际信道数值仍为空。

## 校准、误差运输与统计接口

`calibration-registry.json` 登记角色、所需独立来源和未交付 receipt，不代造负责人承诺。
η 必须来自适用光谱/窗口/epoch 的独立系统效率记录；探测器标称效率不是系统效率。
允许有来源的 Klyshko 类校准，但须证明校准分区与 test 分离并登记方法假设。
目标态校准只支撑条件模型，不升级为原 source-theory 检验。

逐步条件模型必须有共同覆盖区域，不能把各参数的边际区间直接充当同时覆盖。
`transport_radius` 消费完整命名的有理上界并求保守截断和：状态测量 TV、两侧 effect
算子误差、q、visibility、两侧赋值/损失/背景误差、模型余项、漂移与数值误差。
状态项须控制所用测量的 TV（例如由 trace-distance 上界给出）；端口项取所有 latent
及设置的最坏列 TV。随机核收缩与逐层 coupling 的三角不等式给出各 cell 的同一界。
该求和器不证明输入的置信覆盖；未交付 numerical_tv 时，浮点参考表不能签发严格概率锁。

沿用条件检验 α=1/40、校准覆盖失败预算 β=1/100；合计 7/200，剩余 3/200 不重分配。
该预算属于一个条件联合模型检验，不给每张参考表分别重复分配 α。
本草案只接好概率运输与预算接口；NIST 事件解码器/统计执行器在独立接入会话实现并复核。
现有 ETH 的 calibrated/request.json 与执行器不被本草案修改，也不被错误宣称自动适用。

## 格式与冻结仪式

[官方格式说明](https://www.nist.gov/document/bell-test-data-file-folder-descriptions)描述了
原始三 uint64 记录与 processed HDF5 的设置、uint16 点击位图及同步/窗口元数据。
位图的每一 bit 指定一个 pulse slot；必须用预先固定的 mask 判定本地点击。
设置编码中的双触发/无触发不能当作普通二元设置。异常 sync、时钟对齐所用前缀、
端序、实际 HDF5 字段名和 trial 数守恒须在接入前逐项核验，禁止猜字段或事后去异常。
无元数据的旧 compact 文件及派生结果表不作为此版首选输入。

冻结按依赖顺序进行：先签收独立名义装置与控制最优性，再交付校准/epoch/模型误差，
然后固定试次地址、窗口、异常政策、样本量/停止规则与单一统计检验。
独立复核人检查完整试次数守恒、分区不交叠和同时覆盖；记录对应源文件/协议/代码/
Lean 定理与认证的哈希，完成不可变锁后，才另行授权读取评测文件。

任何 test 接触后，设计版本不能通过翻号、调 η/q/visibility 或增大容差进行救援。
接触后的材料转入开发身份；新的检验必须有新版本和未读分区。
本次没有创建锁、发送外联、读取评测档案或安排自动接入。
