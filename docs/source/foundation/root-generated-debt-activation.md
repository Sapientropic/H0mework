## Stable contract

An existing world may activate one law-owned debt row without filtering its old ledger:

```text
base support × optional debt state
├─ inherited responsibilities, claims and budgets remain literal
├─ active face has one equality-sealed debt identity
└─ inactive face has no debt row
```

`DebtActivationLaw` supplies the debt identity/claim, finite budget, strict step events,
settlement evidence and typed obstruction.  Optional phase-terminal and transport families are
separate source receipts; omitting either makes its event fibre definitionally empty.

## Strict payment, terminal and transport

A strict step evolves the complete active fibre:

```text
old rows  --same receipt / transferred--------------> old rows
debt row  --same receipt / maintained / strict <----> debt row
```

A phase terminal must be an independent actual event containing the local settlement it discharges.
Debt zero alone cannot mint whole-support terminal authority.

A generic transport may satisfy `targetBudget ≤ sourceBudget`, but this is only a history
transporter.  For an accepted transfer, bearer, anchor or incidence must undergo an actual
source-registered reassignment while debt lineage and claim remain fixed.  Ordinary same-row carry
is definitionally the same row.  Neither case is a strict payment, a U7 answer or fresh credit.

## Whole-ledger and Noetherian interaction

The generic ledger kernels provide total two-sided evolution over arbitrary inherited fibres; no
finite row table is required.  Their `≤` transport theorem certifies no-refill only.  It does not
certify that a particular domain event is an accepted transfer.

The Noetherian consumer accepts a same-debt macro only in the form

```text
non-refilling history ; exact strict payment ; non-refilling history
```

and derives endpoint strictness itself.  A transport, U7 redirect, carrier revision or local clock
change cannot replace the middle payment.  A fresh budget requires another source-generated debt.

## U7 disposition boundary

Once an obstruction has generated an exact live debt row, the lawful U7 exits remain:

```text
settlement
| strict-budget paid redirect
| theory audit
```

A transport may preserve actual history around a paid redirect; it cannot be compiled directly from
the U7 obstruction into `nativeWrite / next`.  If the old surface cannot express the already generated
update/effect, the theory audit must establish rooted expressibility failure.  U8 then supplies the
minimal coface, while the revised source supplies the concrete realization and first paying write.

## Domain admission test

Before a domain installs `DebtTransportLaw`, it must prove from the same occurrence:

1. the actual transfer receipt and generated target;
2. a real bearer/anchor/incidence reassignment, not merely a renamed state;
3. exact lineage and claim preservation;
4. whole-ledger transport with no refill;
5. that the transfer is subordinate history, not the settlement/payment answer.

If anchor, incidence, claim and row identity are all definitionally unchanged, the event is carry or
observer residual.  Register it at U7; do not mint a process successor.

## Goldbach application

The occurrence-sensitive Goldbach law now installs terminal, strict payment and
`ProjectionRecurrenceResidualAt`, but deliberately omits the optional transport family.  The
path-generated recurrence therefore has empty `TransportAt` fibres and remains an exact
`requiresTheoryAudit` event.  Its U7 row and living causal authority stay active; the former
recurrence-transport/root/process chain is not Goldbach authority.

The same root now installs the exact recurrence/effect and its failure token as sibling projections.
Its operational theory defines lawful realization by the existing U7 answer fibre—not by a caller
Boolean—and that fibre is empty at the exact recurrence.  Consequently the root generates an
`ActualExpressibilityFailure`, fixed failure face, rooted failure and canonical minimal coface.
This pays representation diagnosis only; concrete revised dynamics and the first paying write remain
the next source responsibility.
