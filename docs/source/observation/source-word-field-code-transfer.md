# 原词后观察接回完整 Field 时间传递

原历史 `historyPMF depth` 的完整 Field 读者是
`OriginalHilbert.Actor.nextRead (depth+1) depth`。它在实际有限 actor 上单射；
`CoarseCode.fieldCode` 仅在这些**实际支持点**取回唯一 actor，从其已安装
`runtimePayload.nativeWrite.target` 再执行原 `Fock.actualWord`，最后读 `scanIndex mod 2`。
支持外值固定为零，不声称该延拓是全 Field 上的物理 instrument。
`actual_square` 逐 actor 认回既有 `ObservedCode.readAt`；空词还认回原安装 face。

同源权重经 `mixture_full`、`counted_mixture` 保留完整旧 Field fibre 与新码 fibre：
旧 counted receiver 的 `readWeight` 正是 Field→码的完整条件混合。
`counted_original_field_transfer` 将旧 `IsometricRetainedTransfer.transfer` 在每枚原
Field 实际点的值按该 posterior 加权，生成原 source→bit 任务的最优读值；
输入仍是旧原 Field 的时间传递，并未把码 transfer 冒充为它。

`field_to_code_residual` 精确给出 **actor-history** 上码残差平方＝旧完整
Field 观察残差平方＋粗码新增加权误差。原 **word-law temporal** residual、范数与
重建另由 `sourceTime_original_residual`/`sourceTime_original_reconstruction` 保留。
`CoarseCode.original_code_time_consumed` 同时读两种残差、旧时间消费者及当前
material stage 的整账/next；原 `CopyObservation.ActualRecovery` 直接消费它、
完整 posterior 和原 G 风险正下界。

原作用词 `u ++ v` 的 actor 观察由 `source_query_append` 精确分解为先执行 `u`、
再由实际 `v` 的 `bitWord` 作用。`original_field_action_square` 只在原 Field 的
实际 actor 像成立；支持外的固定零延拓不承担全 Field 作用律。
`source_information_tower` 用同一 `historyPMF` 与既有 native 计数合并生成条件信息
增量；`original_field_residual_tower` 用原 Field 条件传递生成 L² 残差平方增量。
原 `[copyOne]` 对二值任务使前段精确恢复变成严格正的 L² 新误差，同时条件信息
严格增加；非空 native letter 的 bit 翻转信息增量为零，空尾 L² 增量为零。
这只给原观察通道定价：完整 acted word 仍保留 actor，不能把二值擦除写成
完整 source 消失，也不能把标量误差无作用搬到原 G 的 slope/资源单位。

`ActionRisk.original_acted_g_risk_tower` 从旧 `risk_account` 原样保留 after
cost、整词编译斜率及 after effect/decoder 偏差，仅把同一 after 查询的原 clock
残差拆成 before 残差和新 L² 误差。原 `[copyOne]` 的 clock 任务在旧 parity
两 fibre 上最优值为 3、4，作用后全 fibre 的最优值为 `7/2`；原 PMF 给新误差
精确 `1/4`，原词斜率精确 2，故任意 decoder 的**本次**原 G 风险至少为 1。
这是风险内新增的同单位分量，不宣称整个风险相对空词单调增加；原 physical
effect 与完整 acted word 仍在旧 source 账户。原 Copy/Graph、整账及 next 同次消费。

出生后继沿旧 `oldLetter` 将原词 `oldWordAt` 送至 `nextWordAt`；旧新读口与
`bitWord` 均由已有实际作用方块逐点认回。`NativeBirth.original_native_birth_information_loss`
因此直接消费既有 `amount_next`：两拍词观察的信息损失按源历史长度加权，
差额是同一次新增 actor 在 coarse/fine 原计数上的两枚 `informationIncrement`。
原 d3→d4 的 `[copyOne]` 有旧 coarse count 4、fine count 2，给
`5·amount_next=4·amount_old+inc(4)−inc(2)` 且修正项严格正；空尾修正为零。
这不推出未缩放 `amount` 单调，也不把出生信息式说成生成了旧 material 的 next。
原 Copy 同时消费新一拍的信息/Field/G 账户、完整 counted Model 与既有整账/next。

同一 d4 发生还给一个必要的任务反控：`BirthRecovery` 从原五 actor fibre
`{0,2,4}`/`{1,3}` 计算出 before 两个 bit key 的 clock 最优均值均为 4；
`copyOne` 后全 fibre 的最优均值也是 4。因此该原 clock 任务的新增加权 L²
误差精确为零，原 Field 残差平方不变。与此同时，同拍原 `amount>0`，旧
`amount_positive_iff_gap` 给完整 G/Model 粗化 gap 严格正。信息损失与完整
Model 责任没有消失；本任务的额外均值恢复价为零，不能把完整 gap 免费换成
任意标量或把 clock 零增量换成完整 G 风险零。原 Copy/Graph 同根消费正反式。

旧 Recovery 引擎的正权 `error_zero_iff_of_positive` 现给加权误差零值的逐源点
充要式。原 `TaskCriterion.original_task_increment_zero_iff` 直接用于实际
`fieldCode ∘ Actor.nextRead`：一项任务的原词追加增量为零，当且仅当每枚
actor 的旧条件最优均值等于新条件最优均值。对完整原 unit-task 库存，全部
增量同时为零当且仅当新观察没有合并旧 fibre；已付 `amount_lossless_iff`
进一步把它等同于同一 actual word 的信息损失为零。d3 的正增量和 d4 的
clock 零增量／完整 Model 正 gap 说明判据必须带任务与完整 inventory。
原 Copy/Graph 在两拍消费这三条双向式；支持外 Field 点没有被提升为发生。

完整 acted-G 风险现在沿同一实际出生更新。`oldLetter` 逐字保留原
`SourceCopyNativeWord.encode`，因此跨深度保留旧词 `GWord.effect`；原
`values_retained` 与 `old_next_read_at` 使每个旧 actor 的完整 G 像和 decoder key
都同值。对任意原词与同一 decoder，旧 `risk_eq` 的真实 `historyPMF` 权重给

```text
(d+2)·Risk(runtimeAt(d+1), nextWordAt(d,w))
  = (d+1)·Risk(runtimeAt(d), oldWordAt(d,w))
    + ‖G_image(出生 actor) − decoder(出生 bit)‖².
```

末项由原新 actor 的 `SourceCompiledGWord.image` 与原词读口生成，不能由
caller 填值。原 d3→d4 `copyOne` 特化结合旧 d3 任意 decoder 风险 `≥1`，
得到 d4 完整 G 风险 `≥4/5`；同拍 clock 新 L² 增量为零、完整 Model gap
严格正。旧 `Copy.Observation.ActualRecovery` 直接摄入出生式及下界，
`Copy.Graph` 继续消费其原 root、既有 whole-ledger 与 literal next。
这不是原 ledger 新字段或由风险式驱动的新 root 转移；不能把空尾的信息
零修正当完整 G 风险零值。

同一原词的**最优** G decoder 取 `GWord.effect` 作用于既有源 posterior，
`gBest_risk_decomposition` 在原 acted-G risk 中分出它与任意 decoder 的
非负偏差。对出生 key 的旧 fibre 计数 `c`，原 G-space 裸风险满足

```text
T_G(next) = T_G(old) + c/(c+1) · ‖G_born − gBest_old(bornKey)‖²,
T_G(r) = 当拍 actor 数 · Risk(r, gBest_r).
```

旧 source-space inverse residual 没有搬入这里；均值更新的平方始终在
`SourceJointClockGraph.Carrier` 计算。原 d3→d4 `copyOne` 的 born key 为 0、
旧 fibre 计数为 4，原成本与 clock 条件残差给旧／新最优风险精确
`23/4` 与 `44/5`。因此裸总额从 23 增至 44，出生创新平方为 `105/4`，
实际增量 21；同拍单一 clock 任务的新增 L² 仍为零。原 Copy
`ActualRecovery` 直接消费最优式、精确控制与任意 decoder 最优性，
Graph 沿既有 root 整账/next 继续消费。

同拍恢复不再把 G 作用词与观察词锁成一个输入。`ActionRefinement` 固定原
`taskWord` 的完整 `GWord.image`，让细 `read` 与实际 `forget∘read` 各取同源
条件均值，证明

```text
Risk_G(coarseBest) = Risk_G(fineBest)
  + Σ_actor historyPMF(actor)·‖G_task(fineMean)−G_task(coarseMean)‖².
```

原 G 逆读与 actor 正质量给新增 G gap 零值当且仅当已付 source merge gap
及信息损失零值。原 d4 `taskWord=transported copyOne` 保持同一个物理 G
作用；原 parity 细读口与擦除后的 constant 粗读口的源成本分别为 3、4，
两侧原 clock 条件残差相同。于是本次完整 G 最优粗化价**精确为 `1/5`**，
尽管该 clock 任务的新增 L² 为零。旧 Copy `ActualRecovery` 直接摄入方程、
双向零值与固定数值，Graph 沿既有整账/next 消费；此处仍非新增 root
数值字段。

词观察的实际顺序是 nativeWrite 后再作用词。`RootAction.word_native_order_equation`
给出斜率为 `a` 的整份序差；`word_commutes_native_iff_unit_slope` 证明能与原
`nativeStep` 交换当且仅当 `a=1`。原 copyOne 的 `a>1`，且固定 actor 的二值
读值与“先 copy 再 native”确实不同；native letter 是正控。原 native row 只支付
其 own write，非空 copy 的材料与作用保留自身谱系，不被终点同值合并为该行。

跨库存反控从原 `oldLetter` 与后继 `fresh_bit_action` 继续：d2 字母搬入 d3 后仍执行其原 d2.tick.next 物质位，故在全部 d3 actor 上读零；d3 新字母的物质位来自 d3.tick.next，区分 actor 0/1。于是完整旧 future-tail 响应不能由任何 decoder 免费恢复新响应。把旧码用于 d3 新字母的原 source-weighted G 任务时，任意 decoder 的实际风险至少 `3/4`；同一 d3 的 counted posterior、material whole-ledger 与 canonical next 直接同口读出。比较保持两次 tick 的不同 material 身份，没有将它们合成一个 occurrence；此结论排除该具体无效压缩，不宣称一般库存增长必然丢信息。源码见[跨库存无免费出生](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Model/Family/Words/Dynamic/Hilbert/SourceWord/ObservedCode/Future/Growth/NoFreeBirth.lean)。

同一 d3 新字母 G 任务已有反向的实际恢复收益：旧搬运码恒零，新码区分 actor 0/1；原 `gRisk_refinement` 用同一 `historyPMF` 给 `Risk_old = Risk_fresh + gGap`，`gGap>0`，源条件信息差额也严格正。最优 decoder 由已有原 posterior 生成；新码仍有风险 `≥1/2`，没有冒充完整 actor 恢复。原 Copy counted posterior 消费完整未来响应的条件 fibre、整账和 next。源码见[恢复方程](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Model/Family/Words/Dynamic/Hilbert/SourceWord/ObservedCode/Future/Growth/Receiver/FreshRecoveryGain.lean)与[原消费者](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Copy/Observation/FreshRecovery.lean)。

原 d2/d3 字母继续经旧 `oldLetter` 进入任意 `runtimeAt (3+offset)`：两枚 slot 的材料分别由原材料律精确回读 runtime 3/4，前者当前 bit 对所有该拍 actor 为零（完整 future-response 函数因而对 actor 同值，但不必是零函数），后者仍区分 actor 0/1。每拍按自己的原 `historyPMF` 与同一个 transported d3 G 任务生成 `Risk_old = Risk_fresh + gGap`、`gGap>0` 和严格正条件信息差额；原 Copy 对该拍**全部 actor**读回完整 future 条件分布、whole-ledger 与 next。此式是每拍的同任务比较，不推断跨拍风险单调。见[原材料与搬运](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Model/Family/Words/Dynamic/Hilbert/SourceWord/ObservedCode/Future/Growth/Receiver/PersistentMaterial.lean)、[原 G 方程](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Model/Family/Words/Dynamic/Hilbert/SourceWord/ObservedCode/Future/Growth/Receiver/PersistentRecoveryGain.lean)及[原消费者](../../../../SaturationMonoid/NoIslandNoMagic/CanonicalArithmeticState/ParticleWave/Fock/Runtime/SourceHistory/Copy/Observation/PersistentFreshRecovery.lean)。
