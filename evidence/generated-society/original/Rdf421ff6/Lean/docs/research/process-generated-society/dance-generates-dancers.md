## 一、已经闭合的最大结论

社会科学没有免费背景。个体、权力、货币、空间、概率、理论与法律都必须说明：

- 由哪一枚 actual occurrence 生成；
- 怎样进入 lineage 与 renewal；
- 哪个 observer 忘掉了什么；
- residual 由谁承担、谁消费；
- 旧 law 无法表达时怎样生成 U8；
- 哪一枚 whole-ledger write-back 原生生成 next。

最终根法不是一张永远增长的应用目录，而是以下关闭条件：

\[
\boxed{
\operatorname{FINAL}(M_\infty)
=
\operatorname{RootLawComplete}(M_\infty)
\land
\operatorname{U8Available}(M_\infty).
}
\]

对任意 source-generated legal attempt，最终 eliminator 只有四个出口：

```text
lawful presentation
| typed rejection + visible residual bearer
| rooted installed action + whole-ledger successor + generated next
| exact failure + same-row U8 + revised first write + row-next
```

不存在第五种账外 authority。presentation 与 rejection 不写 world；action 与 U8 是写入叶并且不交。
在当前 M14 local root，same-occurrence legislation fibre 为空，所以 local action 类被构造性排除；该类仍携
真实 generic action payload，不是空命名。实际 rooted 正例经同一 source event 进入 typed-distinct external

`U8Available` 是条件可用性：真实 compiler 选择 U8 时，完整 failure/same-row/write/next package 必然可读；

## 二、舞蹈怎样生成舞者

设 \(O\) 是 source-backed occurrence。可取得 actor standing 的种子只能来自它自己的 trace：

\[
\operatorname{TraceSeed}(O)
=
\left\{
s\ \middle|\ \exists x\in\operatorname{trace}(O),\
\operatorname{SeedAt}(O,x,s)
\right\}.
\]

lineage 等价关系为：

\[
s_1\sim_L s_2
\iff
\operatorname{lineageOf}(s_1)=\operatorname{lineageOf}(s_2).
\]

actor 的结构口径是：

\[
\boxed{
\operatorname{Actor}(O)
\simeq
\operatorname{TraceSeed}(O)/{\sim_L}.
}
\]

这里没有预装个人。actor 由 lineage fold 生成；群体身份由 group transport 生成；攻守、雇佣、照护、
管理、债权等角色由 relation phase 生成。三者不得合并成一枚 `PersonId` 或 role registry。

birth、survive、merge、split、exit 与 succession 是 lifecycle dispositions。Player、Coalition、Institution、
Strategy、Payoff 与 Power 都是同一 occurrence 的 dependent faces；它们可被经典 readout 观察，却不能反向
铸造 occurrence authority。

“舞蹈生成舞者”因而不是隐喻：先有 source event、trace、relation 与 fold，后有可持续识别并承担责任的 actor。

## 三、M∞ 的八个面

这些面共享同一 root，不是八套本体。

### 3.1 Base：身份由 occurrence 与 lineage 生成

没有无来源 actor，也没有由姓名、账户、模型标签或数据库主键直接产生的 standing。身份变化必须是 birth、
transport、merge、split、exit 或 succession 的 source-owned disposition。

### 3.2 R：权力与 standing 必须续约

\[
\operatorname{Authority}(A,t+1)
\Longrightarrow
\exists e_t,\ \operatorname{Renews}(e_t,A).
\]

选举续约 mandate；货币续约 acceptance；关系续约 maintenance；产权续约 boundary/enforcement；AI 或机构
standing 续约 trace、consumer 与 responsibility disposition。没有新事件却无限延长的 claim 是 free-eternal
authority。

剥削的最小结构签名是：

\[
\boxed{
\text{renewal-control asymmetry}
+
\text{debt-flow asymmetry}.
}
\]

### 3.3 K：observer 不是世界

已经生成的最强反例是两条不同 actual replay/path：

\[
\gamma_1\neq\gamma_2,
\qquad
\operatorname{NormalForm}(\gamma_1)
=\operatorname{NormalForm}(\gamma_2),
\qquad
K(\gamma_1)\neq K(\gamma_2).
\]

因此 normalized Forget 非单射、无 authority-preserving section，也不能重建 occurrence identity。余额、偏好、
GDP、风险分数、档案叙事与模型输出都可以是有用 readout，但不能独自决定 cause、repair 或 world update。

### 3.4 U：改革与革命是同一 root 的两种 disposition

旧表示能承担 residual 时，更新走 bounded transport；出现 exact representation failure 时，同一 row 生成 U7
audit、minimal coface、U8 first write、claim migration 与 new consumer。U8 不是第二法院，也不制造物质资源。

### 3.5 C：失范是 occurrence/capacity 相变

令 \(\lambda_O\) 为 source-generated occurrence arrival rate，\(\mu_L\) 为 lineage compiler 在保留 provenance、
renewal 与 responsibility 时的结算容量：

\[
\lambda_O<\mu_L\Rightarrow\text{stable},\qquad
\lambda_O\approx\mu_L\Rightarrow\text{critical},\qquad
\lambda_O>\mu_L\Rightarrow\text{anomie}.
\]

rate 与 capacity 必须来自 trace/compiler；外部 scalar 不能直接选择 phase。

### 3.6 S：社会空间由 crossing 生成

\[
\operatorname{SocialSpace}(O)
=
\operatorname{Fold}
(\text{crossing, accessibility, adjacency, flow, boundary certificates}).
\]

国界、地契、平台分区与交通可达性都是 maintained relations。boundary authority 若持续存在，就持续产生
maintenance debt。这里消去的是社会、法律和经济的免费空间背景，不是否定 ambient physical geometry。

### 3.7 P：概率是带 source 的 observer readout

对 observer \(q\)、source-generated measure \(\mu\) 与 visible fibre \(q^{-1}(v)\)：

\[
\operatorname{Prob}_{q,\mu}(E\mid v)
=
\frac{\mu(E\cap q^{-1}(v))}{\mu(q^{-1}(v))}.
\]

任何取得 authority 的概率都必须交代 source、observer、normalization、conditioning fibre 与 consumer。
“无原生骰子”拒绝的是无来源概率值直接取得 world authority，不是先验宣布一切 ontic indeterminacy 都不存在。

### 3.8 Σ：理论本身也是 occurrence

只有被实际采用、执行、测量或制度化的理论才进入 \(\Sigma\)。一旦进入，它必须登记发布者、受益 lineage、
被压入 kernel 的 bearer、maintenance debt、退出/申诉与 downstream effects。理论不能一边改变世界，一边把
自己伪装成系统外相机。

## 四、典范社会

所谓典范社会是：

> 没有无来源的身份，没有免费永恒的权力，没有不可见的残差承担者，没有冒充真理的 observer，
> 没有禁止自身修订的法律，并且 standing bearer 拥有不依附待退出角色的可行动未来。

这不是终态，而是 update 下的根法不变量：

- actor 由 lineage 生成；
- power 与 service 每拍真实 renewal；
- residual 始终有 bearer 和 independent consumer；
- observer kernel 可以被 witness return 穿透，但不会因此变成全知；
- ordinary action 与 failure-generated U8 穷尽合法写入；
- 每枚 next 都来自同一 occurrence 的 whole-ledger disposition；
- successor 永久保留再次 U8 的能力。

携证要求落在权力而非人身上：

\[
\boxed{
\operatorname{ProofCarryingPower}
\quad\text{而不是}\quad
\operatorname{ProofCarryingPersonhood}.
}
\]

人不需要证明自己“值得存在”；分类、剥夺、征税、产权、平台 gate、强制结算与法律必须证明自己的 source、
bearer、consumer、exit、failure 与 next。
