1. a type-level claim gap;
2. target or branch smuggling;
3. a source/occurrence mismatch;
4. a residual bearer or consumer that is not independently generated;
5. an axiom/provenance discrepancy;
6. a lawful encoded attempt that needs a fifth outcome;
7. a positive branch for which the named negative control does not actually exclude the forbidden
   interpretation.

Renaming an existing witness, restating a no-go, or constructing a second registry is duplicate
work.
