# ef0003.1：公开完整计数的回顾性同源纤维

ef0003 的两次科学首算已经形成。两条路径分别生成满足全部六项训练 CI、但越出原留出 CI
的具体合法源。因此，六项训练约束不蕴含统一留出落带。本版消费已经公开的其余六项 CI，
生成 F_all=F_train∩F_held 的完整条件源纤维；它是回顾性联合相容性与源关系认证。
原训练纤维、source-stage 摘要、首算、越界证人及其判决保持。

## 同一个源与完整统计域

源 law、实际端口、phase-before-window、五 fresh pulse OR、背景、四接收角及物理域全部
沿用 [ef0003](criterion.md)。原 po0003 的共同 N、setting 条件界、全 feature/run/mask
预算和 alpha=1/20 保持；只消费其已经生成的 exact_lower/exact_upper。

相同本地设置的 single 概率在具名同源 stationary law 下相等。四个完整输入区间为
A0=sA_cell[0]∩sA_cell[1]，A1=sA_cell[2]∩sA_cell[3]，
B0=sB_cell[0]∩sB_cell[2]，B1=sB_cell[1]∩sB_cell[3]。
每个交集须保留原两条 CI 的来源；交集空即拒绝本 law 的联合相容性，不改统计域。
四 joint 各使用 j[0..3] 原完整 CI。它们同时约束同一 k=(1−2λ)T，保留共同 slab 交集；
不能为各格选择不同相位，不能先按某个最佳拟合源丢弃其余分支。

四 inverse-single 坐标与自由 loss 的主图谱、source polytope 与自由 loss 的独立图谱
分别重新生成外覆盖。完整合法源落入初始域、contractor 的 outer 性、全分割树、排除依据、
所有 cap/boundary 与配对读出分别验收。cap 限制收紧程度，不允许丢弃尚未排除的源。
主路径 16384 splits；独立路径 24576 splits；depth、width、精度与退化规则沿用 ef0003。

## 非空、配对读出与结果规则

固定成员选择沿用 ef0003 的四坐标分数、loss j/64 与 phase midpoint/lower/upper；
新成员由本版全 CI 生成，最多 64 个。主/独立 native 坐标差异保留，不强迫同一采样点。
非空必须由同一个物理源的全部十二项概率数学包络落入各自原 CI 证明。
actual positive Γ/Fock prefix6 加原 numberMass 尾用于独立核对成员；真空点击严格零，
不重归一前缀，不把窗口后混合替代逐 pulse phase mixture。

每个保留块存储同一源、共同 k、四格完整 outcome、joint 和/差及 CH。
joint/single 交集只限制同一源的读出；展示 hull 不替代配对集合。
CH、控制响应或其他不变量的严格符号只由整块配对包络或具体证人验收，不能因相容性而置真。
全域符号未决时保留未决；没有成员不等于整个纤维为空。

本版可以签收：完整条件源外覆盖、具体全数据合法源、no-signaling/shared-phase 源关系，
以及实际核过的配对读出。实际 epoch/source mapping、历史 apparatus optimum、
controller advance 和新的通用无限 Born kernel 身份不由本版赋予。
新公开观测消费者分别记录训练统一预言反证与全数据相容性，不把后者改标为留出通过。

## 冻结与独立性

本合同、各科学程序和每次修复先提交后执行。两条本版科学路径从共同公开合同、原源 manifest
及各自冻结 ef0003 程序起步，首回执形成前不互读对方的新程序或结果。
旧科学首与本版首分别保留完整字节和 source bindings；不读取试次事件、不新增实测、不外联。
