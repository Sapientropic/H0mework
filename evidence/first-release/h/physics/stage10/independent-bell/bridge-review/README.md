# ETH Bell：相位桥接与三层裁决

**r0002 拒绝的是未经充分仪器验证的理想联合模型。底层理论当前无法裁决。**
本次改进先解决桥接可识别性，再决定是否具备新锁条件；旧锁和全部原结果保持。

## 两格反号已经定位到哪里

独立复核作者定义得到 `S=E00−E01+E10+E11`，bit0 阻断脉冲、bit1 放行，
g/e 分别记作 +1/−1，见[官方证据与精确页码](public-calibration.md)。
原 Eq14 状态与标准脉冲计算给出：

```text
ψγ = (|eg⟩ + exp(−iγ)|ge⟩)/√2
δ = γ + φB − φA
(E00,E01,E10,E11) = (cosδ, −sinδ, sinδ, cosδ)
S = 2(cosδ + sinδ) = 2√2 cos(δ−π/4)
```

**旧锁的 γ=0、θgeo=−π/4 对这个官方 CHSH 定义给出 S=0。**
它与作者称该名义几何角为最优设置的描述不相容。这是一项在揭盲前就能发现的
控制映射自洽性错误；旧合成测试验证了所选矩阵算法，却漏掉了这个独立语义闭环。

δ→−δ 恰好反转两格非对角相关。若任意允许改 setting 或按 setting 翻 readout，也能
产生同样表象；官方编码没有给这些翻转提供依据。因此不从已知四格计数挑一个修复。
需要给出原始相位命令、每个 setting 的有效 unitary 与共享参考帧的对应。
真正须辨识的是组合 δ 及相对手性；γ 与站间参考角可相互抵消，不要求把两个规范依赖量
分别测定。沿用原源允许的 local preparation operation 即可登记这条桥。
完整推导和等价候选见[相位约定](phase-conventions.md)；直接矩阵检查见
[pulse_model.py](pulse_model.py)。**具体实物映射仍未唯一识别。**

## 新的裁决层次

| 层次 | 本次 r0002 的结论 | 下一次的独立输入 |
|---|---|---|
| 仪器桥接 | 未闭合；已发现最优角/相位定义不自洽 | 已知控制态、带方向的相位步进、原始 setting/readout 编码、运行与校准时段对照 |
| 条件模型 | 原冻结理想模型被拒绝；保留全部数值 | 校准联合置信域、已登记近似与漂移界、预设适用性及检验力 |
| 底层理论 | **inconclusive**，不分配理论或仪器的责任比例 | 未被校准吸收的源预测内容，以及足够识别理论差异的桥/误差证据 |

未来桥接验证须有明确的正确编码检验、相位方向检验及误差上界。一次“不拒绝”不能代替
桥接成立；条件模型相容也不能自动签发理论通过。理论源参数不随测试结果变化。

## 公开校准材料的实际用途

Fig.5 是已做 offset 校正的相关函数扫描，缺原控制角、offset 误差、样本数及 run join。
Fig.2 是经过 readout correction 的目标态层析。它们可供本次揭盲后桥接研究，无法直接
生成覆盖当前主事件流的独立仪器置信域。各自事实和未恢复材料由
[public-calibration.md](public-calibration.md)统一维护，不补零误差或虚构 error bar。

首批 100000 事件在原 r0002 下的 L2 信息访问记录不变；用于新版本设计时归为 L0 开发。
新 test 的主文件余段仍隔离。扫描与主文件是否不交叉、校准是否适用于选定 test 时段，
必须有来源证据；不同文件名或“另一次实验”的描述不足以自动通过。

[calibrated/](../calibrated/README.md) 已实现带校准不确定性的前向区间和检验器，
并将缺校准时的默认行为改为不形成新锁、不启动新裁决。当前
[输入责任](../calibrated/request.json)没有填入假参数，未产生 r0003 锁或新经验结论。

本轮是原同源 Bell 概率的 subordinate 仪器桥接工作；原 source、SpinPair occurrence、
whole-ledger 及既有 Stage10 形式封印保持。静态 empirical-contact 证明记录条件模型残差
与下一输入责任，不承担现实相位校准或底层理论裁决。
