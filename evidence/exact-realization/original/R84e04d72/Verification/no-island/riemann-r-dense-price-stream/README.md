# 原 Division 的完整 K 价格流

一条价格流来自完整 Hilbert 场，当且仅当每个有限残差为零，且有限逆的能量统一有界。有限逆之间的正交增量给出 Cauchy 读回。

在原 Division 图上，同一组稠密 K 地址读原全物理投影。输入价流恢复完整 Γ² 图，原 R 作用产生下一条价流，并同读原关系库存、整账与后继。

```sh
python3 Verification/no-island/riemann-r-dense-price-stream/certify.py --repo "$PWD" --compiled-root "$CP617_COMPILED_ROOT" --base-lean-path-file "$CP617_LEAN_PATH_FILE" --output "$CP617_AUDIT_DIR"
```

加 `--verify-inputs-only` 核对正式 Main、选中对象和已付来源。
