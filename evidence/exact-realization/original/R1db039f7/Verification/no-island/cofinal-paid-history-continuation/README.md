# 原付费历史的续接与固定目标付款

在固定目标 Goldbach 的实际运行态上，严格付款追加原前后端点之差。同一新关系重写原末端生成元，并与原逆、整账、字面后继及独立终态收据相接。原 R 的 Division、位置隙、K 与整账和后继也在其自己的原运行态上直接核验。
