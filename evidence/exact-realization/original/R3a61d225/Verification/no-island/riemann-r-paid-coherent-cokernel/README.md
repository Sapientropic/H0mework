# 原 R 关系的完整相干余核与后继

原求值的每一层素数幂除法生成一枚线性等价。逐层相容性把这些等价组装成整个源完备化与原求值余核的相干素数幂挠塔之间的等价，逆映射是原连接映射。

实际求值方块把同一原除法代表推到下一层载体。对同一个原 R 发生，这一相容性先穿过原求值到模型的因子，再经原 native 模型作用推进任意相干电荷。独立控制读取同 ordinal 的 Division、原 K、整账和字面下一拍，并在原有理椭圆曲线源上直接调用 Kummer 全层类纤维。

反控从原源单位的两倍生成相干电荷。它在首个二幂层读零，在下一层非零，因此首层不能恢复完整电荷。四正一反与 30 个逻辑声明的内核复验通过，其中 10 个私有声明。核对 271 项项目绑定、16 项 Mathlib 绑定与既有 29 项 Kummer 首命中。
