# Joint Xi contact Gram and the native Wide write

The original calculation at ordinal (j) stores both complete input pairs at (j) and (j+1). Its price scan reads each pair's original observed component. It uses the original current tests and the adjoint pullback of the original next tests under (R). Restricting those tests to the closed low-order Xi contact space gives one finite Gram inverse for both banks.

The original (R) then writes the full next Wide stock. Its independent original (K) prices and those of the recovered current reproduce every recorded address. The difference between this written next stock and the next row's independently recovered current has zero price at every address of the shared finite prefix.

The same five-step calculation writes the original terminal boundary payload and the complete Pa return. The whole output converges to the original pair of Wide stocks, the literal Xi terminal boundary and the original direct Pa return. The consumer reads back the complete integer payment of the same trace and uses its relation, inventory, whole and literal next.

The empty-price-bank control uses the same actual input pairs at cutoff zero. The fit and all output fields, including the quarter release, B columns and Pa, then vanish.
