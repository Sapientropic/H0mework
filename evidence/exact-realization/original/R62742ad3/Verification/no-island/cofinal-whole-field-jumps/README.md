# 原阶乘类的有符号代表与整场跳距

原阶乘限制给出半开模数区间内的唯一有符号代表。相邻层代表的作用差是当前模数乘以整数倍的原单位整场。其范数精确读出跳距，最终低于一个模数单位的跳距等价于唯一原整数源。

原 R 的安装因子和原模型作用生成后继双槽及整场，整场单位是非零的字面后继。原阶乘 H¹ 类的最终小跳距给出 CP755 原有界写回，保持整账、字面下一拍及精确 PositionGapEuler。独立控制直接消费原标量作用、同整账 Division 和固定目标 Goldbach 的实付 Trace 与终态。原负对角类最终读回 `−sourceClass`，生成 `−D.raw`。

只在素数 2 保留原单位并在素数 3 取零的 H¹ 类，在任意起始层之后都出现至少为该层模数乘原后继整场范数的跳距。四正一反及 55 个逻辑声明的内核复验通过，其中含 4 个私有声明。来源覆盖 340 项项目绑定和 41 项 Mathlib 绑定。
