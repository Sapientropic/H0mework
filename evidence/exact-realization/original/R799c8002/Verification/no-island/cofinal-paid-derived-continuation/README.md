# 原付费历史的导出续接

原付费词的系数与末端生成元给出关系项和生成元项的回缩。实际续接包含与原微分交换，并由追加关系生成显式余链同伦。把同一映射延拓到整数分次后，得到导出范畴中的同构及零余纤维。

原 R 的字面联合源码预算给出四个活跃付款槽。每槽直接消费原续接、整账与字面后继，同一运行态的 Division、位置隙、K 及模型后继独立读回。固定目标 Goldbach 在自身的运行态消费同一导出构造并保留原终态收据。

反控保留原 R 的最后实际关系，删去其微分支付后，该关系的像在旧关系微分的商中仍非零。四正一反与 112 个逻辑声明的独立内核复验通过，其中含 92 个私有声明。来源核对覆盖 296 项项目绑定与 18 项 Mathlib 绑定。

python3 Verification/no-island/cofinal-paid-derived-continuation/certify.py --repo "$PWD" --compiled-root "$CP748_COMPILED_ROOT" --base-lean-path-file "$CP748_LEAN_PATH_FILE" --output "$CP748_AUDIT_DIR"
