# 原付费余链的严格极限与同伦极限

实际相邻满射逐度生成乘积差 `1−shift` 的原像。它的核是原余链塔的严格极限。该短正合序列给出严格完成到同一原根的同伦极限的拟同构，保每层限制，并与整个余锥作用交换。

原 R 的四个实际付款槽均沿原付费余纤维的同一过渡作用推进，保留原整账和字面后继。独立控制同时读取原 Division、位置隙、K，以及固定目标 Goldbach 在自身付费词上的导出作用与原终态。

反控取相邻作用为乘二的整数塔。交替序列 1,0,1,0,… 在原乘积差下无原像。四正一反及 101 个逻辑声明的内核复验通过，其中含 43 个私有声明。一枚编译器递归伴生项单独核对，逻辑声明对它的引用数为零。来源核对覆盖 314 项项目绑定和 32 项 Mathlib 绑定。
