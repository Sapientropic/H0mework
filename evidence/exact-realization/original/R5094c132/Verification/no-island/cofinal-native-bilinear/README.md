# 同一原生算术发生的素数幂双线性作用

任意整数双线性作用由原两项的素数幂商层生成，并经相容限制组装成整个完备化上的作用。原两源的嵌入与生成的双线性作用交换。

在原 Fock 算术运行态上，同一次发生的两份材料生成兄弟作用和依赖作用。兄弟作用读到字面下一 current，依赖作用读到原 joint fold，两者保留同一个 occurrence、整账与原安装消费。原兄弟表达式保持两个有序增量和交叉增量。独立的原 R 关系仍从自己的源直接读取相干后继及整账。

反控取原实际 seed 的两个二倍增量。交叉项在模 4 消失，在模 8 首次可见，删去它会改变该层结果。四正一反与 39 个逻辑声明的内核复验通过，其中 16 个私有声明。核对 275 项项目绑定和 17 项 Mathlib 绑定。

```sh
python3 Verification/no-island/cofinal-native-bilinear/certify.py --repo "$PWD" --compiled-root "$CP744_COMPILED_ROOT" --base-lean-path-file "$CP744_LEAN_PATH_FILE" --output "$CP744_AUDIT_DIR"
```
