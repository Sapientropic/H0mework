# 原付费余链的素数幂塔

原整数作用逐项生成素数幂商、相干完成与分离商上的余链作用。原层限制构成余链塔，逐次原模极限给出整个余链极限。实际付费续接的正向和逆向映射都是原层作用的极限提升，原收缩分量也与各读取交换。

原 R 的四个实际付款槽逐一读取同一原 `tick` 的前后付费词。每槽消费两枚相干余链极限、限制与分离商作用，以及原整账和字面后继。独立控制读取同次 Division、位置隙、K 和模型后继，并在固定目标 Goldbach 的自身运行态核对原付费余链与终态收据。
