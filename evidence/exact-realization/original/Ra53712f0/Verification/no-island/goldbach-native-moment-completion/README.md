# Goldbach 原 actor 的四矩停点

逐拍四个有理矩给出原相邻整数作用的 Hankel 阶。首个零阶标定停点，未见零阶时取已测表的字面末界。

原种子与停点前的解码整数作用生成末态。实测停点的前一地址消费同一原收据、整账、后继及独立 Reached 或 Exhausted。

```sh
python3 Verification/no-island/goldbach-native-moment-completion/certify.py --repo "$PWD" --compiled-root "$CP616_COMPILED_ROOT" --base-lean-path-file "$CP616_LEAN_PATH_FILE" --output "$CP616_AUDIT_DIR"
```

加 `--verify-inputs-only` 核对正式 Main、选中对象和已付来源。
