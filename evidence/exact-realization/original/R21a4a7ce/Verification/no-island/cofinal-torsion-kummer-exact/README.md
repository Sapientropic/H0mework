# 原素数幂挠塔的相干核与 Kummer 类

源挠元的统一幂界给出固定的降层步数。把任意选取的高层环境代表乘以这一步的素数幂，得到相容代表。因此，原相干连接映射的核等于相干环境挠塔的像，而且每个核元素的环境提升唯一。源挠子模的 Noetherian 性生成所需的统一幂界。

原有理椭圆曲线的高度证明有理挠元有限。由此，同一原 Kummer 余核的两个相干类在每一层的 H¹ 类相等，当且仅当它们之差来自唯一的相干几何挠元。独立控制还直接调用既有原 R 的整账及字面模型下一拍。

反控在 ℚ/ℤ 上取恒等求值。各层的二幂挠类 [1/2^(j+1)] 相容，且第零层非零；它们组成的相干类在余核挠塔上却为零。四正一反与 24 个逻辑声明的内核复验通过，其中 11 个私有声明。核对 268 项项目绑定、16 项 Mathlib 绑定与既有 29 项 Kummer 首命中。
