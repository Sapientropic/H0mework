# 原 R 差分价格的有界逆

Cayley 幂的线性增长界给缩放级数提供可求和上界，得到作用差分的双侧逆与显式范数预算。原 R 的预算由已付完整 Γ² 图上的 lifted Cayley 作用提供。

同一原 K 地址的差分价格恰为字面后继价减当前价。完整差分价流与原准入价流双向复原，并读回原两拍图、关系库存与整账。原非零图的反控排除全部差分价格归零。

```sh
python3 Verification/no-island/riemann-r-cayley-effect-price/certify.py --repo "$PWD" --compiled-root "$CP621_COMPILED_ROOT" --base-lean-path-file "$CP621_LEAN_PATH_FILE" --output "$CP621_AUDIT_DIR"
```

加 `--verify-inputs-only` 核对正式 Main、选中对象和已付来源。
