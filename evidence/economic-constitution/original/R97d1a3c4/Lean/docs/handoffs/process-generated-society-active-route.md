## 全局目标

把社会 primitive 表达为同一 source-generated、renewed、observer-bounded、residual-accounted、
exit-capable、self-revising process：

```text
canonical society
= no source-free identity
+ no free-eternal power
+ no invisible residual bearer
+ no observer pretending to be truth
+ actionable exit capacity
+ source-owned law revision
```

UBI 的承重 mouth 是 source-backed purchasing-power renewal 在旧角色失效后仍生成 actionable continuation，
并让 payment、route、service、bearer、consumer、repair与self-U8都来自actual occurrences。

## 当前最高杠杆责任

full-history first arithmetic locus与M14 whole-sink接线已经闭合。当前最高杠杆责任转向 **maximal necessity independent
countermodels**：证明CanonicalSociety的每个现有承重gate都不是可删除装饰。反例必须保留其余已经生成的visible readouts与
actual authorities，只让被删除gate对应的source/standing/payment/route/service/noncapture/residual-consumer/observer-bound/
renewal/U8/birth/terminal distinction失效，从而产生typed exact failure或异occurrence同像异authority；不能把所有失败塞进
一枚closed enum。

```text
current installed CanonicalSociety gate / dependent certificate field
→ delete exactly that authority while preserving every independent generated face
→ generate a same-visible typed counter-occurrence or an exact empty consumer fibre
→ prove no remaining gate reconstructs the deleted authority
→ consume the countermodel in one maximal-necessity direct consumer
→ expose the dependent family through the existing canonical-society whole sink
→ recompute the next stronger nonredundant obligation
```

验收约束：

- necessity index必须来自当前root已安装的dependent certificate mouths，不得新建未来封闭的gate ontology；
- 每枚反例只删除一个authority mouth，并明确证明其余独立Payment、standing、bearer、consumer、next与observer readout仍在；
- 同visible反例必须使用两枚不同actual occurrences或合法different-authority restrictions，不能用Sum tag、caller pair或裸数值；
- empty-fibre反例必须排除target-smuggling、空真、错误provenance与“把本就缺失的目标放进premise”；
- 已闭合的full-history earliest locus作为necessity正例消费，不能重开为date ontology，也不能把d9 terminal或A14 final倒填；
- whole sink只存M∞ foundation与same-occurrence factorization，不复制payment、field、gate、birth、channel或future registry；
- current gate frontier必须对当前已生成vocabulary完整而对未来开放，不把death/birth/channel kinds写成closed ontology；
- actual play与search同根分权；empty local ledger仍保留external payment/residual consumer；
- 不新建社会时间本体、death/publication registry、第二fold/occurrence/root/ledger、completion oracle或完成未来。
