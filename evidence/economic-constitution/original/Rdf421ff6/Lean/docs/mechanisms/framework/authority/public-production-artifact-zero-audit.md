## 全Nat范围与成本单位

每路有限清单中的 cut 与成本检查先覆盖地址0…5、全部七种 Good。
原实际流的完整有限支持及清单外零库存证明，再将每路已检查的 floor／成本扩到全部 Nat 地址。
Raw 的汇总与 Ledger 的顺序 fold 各自通过物量平衡，精确等于本源末库存。

两条被比较路线都执行25帧，包含参与命令、资源拒绝、供料、退出后生产与重返。
两路各自核实：全部 Nat／Good credit 相等；debit 仅母细胞劳动少1；原金融矩阵／完整 Run 与 claims 对齐。因此共同劳动单位的成本红利是 `1 > 0`。
Ledger 另验末态劳动库存差等于该成本红利，不把库存差另加一次，也不只凭库存差签发红利。

任意旧合法后继能力仍由同源完整 carrier 差保持；所有后续实际 current 保开放，任意原词无完整资本 kernel。
每个获准物量 debit 只涉及自己的签署者，原任务的责任和债不因审核消失。
