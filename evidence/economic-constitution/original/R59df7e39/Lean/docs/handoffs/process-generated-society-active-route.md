# Process-generated Society Active Route

本卡是公共功能经济生成线的唯一实时入口。稳定机制见[实际计量](../mechanisms/framework/authority/public-native-recovery-metering.md)、[规划](../mechanisms/framework/authority/public-function-bounded-service-planning.md)、[学习](../mechanisms/framework/authority/public-function-owned-learning.md)及[融资](../mechanisms/framework/authority/public-function-source-financing.md)；实质跃迁见[协调ledger](../ledgers/society/public-function-coordination.md)。

## 全局目标

对任意合法历史与有限可行任务，仅凭当时分布式观察，生成无价格、无市场批准、无中央全知的实付计划或精确阻塞。同一自适应对手下给出全责任向量不劣的实际替代，存在改进则严格改善，否则给出同域非支配证明。旧合法后继、挑战、修订与创新开放，规划者／验证者可替换及独立复核；俘获且退出能力为零的当前状态仍在域内。贡献结算不生成永久控制权或未来否决权。

## 这些闭合改变了什么

目录已进入默认Stage的真实可暂停执行。NativeProgram.Code原生区分replay／catalogue，Cursor只推进当前子Session一次；子Session完成才把同次回执交continuation。默认Metering／Quoted依次消费first invoice→CatalogueSource.Session→second invoice→SearchPaid；未完目录保原游标，不能提前启动第二invoice或搜索，也不在恢复时重新生成已付目录。

NativeProgram.Event.catalogue逐一携带counted／emitted／prefixed／closed。History、move_appends／move_decreases与completed_work认同实际前缀、每步一事件及完成回执；Stage在原搜索事件旁保留完整native work。既有Micro.fullWork和Restoration.wordCost／capacity随该work计数，Bank.restorationEvent把实际目录步纳入Bank.run.work，Payment.phaseSlot将每个已执行工作位置注入先前成功票据且跨阶段不碰撞。有限额度耗尽时保实际游标和未处理债；不从phaseSlot推出自动额度足以完成整轮。

第二invoice仍直接读取同次目录units，SearchPaid读取同次rows；拒付／成功Archive源认同、原前缀树顺序与重复、原结果／完整责任和own next保持。非计算rank只作守恒证明，实际move／completed不先执行未来continuation求fuel。新增native finish和每个单invoice leaf finish均作为真实控制事件计数。
