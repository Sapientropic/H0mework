# 原带符号关系词的分级作用

同一携入事件的每个带符号项在字面后继库存取得原请求地址。该次实际材料的原环境和已执行增量生成完整的旧值与效果配对。

各项的请求坐标经原列合成生成该词的 Gram 右端。加上整词响应会平移原像逆的全部系数解，并保留任意输入值的 innovation。字面第二次 born 通过已有 residual 读取同一结果，沿原 site 读取整账、两份库存和规范后继。

四正一反和 26 个新逻辑声明通过严格复验，含 12 个私有声明。反控用一个有负系数的变量关系词得到非零配对 (−1, 1)，两支相加为零。原 CP775 的私有 `synthesis_single` 以同一对象及完整声明复用。

```sh
python3 Verification/no-island/graded-relation-action/certify.py --repo "$PWD" --compiled-root "$CP778_COMPILED_ROOT" --base-lean-path-file "$CP778_LEAN_PATH_FILE" --output "$CP778_AUDIT_DIR"
```
