# 原生出生的源作用与 Feed 收据

新注册请求的原预算生成首个已付局部步，此步保持注册 raw。此前原生收据选中的 decoder 写入 active 环境。其与旧 active 环境之差作用于原完整源词，给出旧值和效果配对。

同一携入事件的带符号项在原 Feed 写前库存取得请求地址。该执行收据保存 decoder、typed Trace 和写后库存中的完整段。原 packet 等式将收据带到字面下一 site，保持 signed 值、原整账、两份库存和规范后继。

四正一反和 43 个新逻辑声明通过严格复验，含 12 个私有声明。通用整数变量控制取旧值 3、decoder 8 和系数 −2。出生写入产生 (−6, −10)，首次局部的零增量给出 (−6, 0)。
