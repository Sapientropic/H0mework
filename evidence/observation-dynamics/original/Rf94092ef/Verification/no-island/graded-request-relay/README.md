# 原库存请求的后继转接

原请求读回事件和局部项的正向地址。库存随实际 Feed 写回保留原位置。同一原生后继的抬升事件给出新库存请求及其有号系数。

新请求进入后继 site 的实际材料和增量，产生完整旧值与效果列。该列进入原 Gram 右端及其 born 消费。整账、规范后继与两份库存由同一 site 读取。反控用库存中两个同值事件，分别读出不同的请求位置。

四正一反和 50 个新逻辑声明通过严格复验，含 18 个私有声明。沿 CP776 原视图及 CP530 的七枚已有对象复用，CP339 保持原 canonical 生产签权。两条重合导入边共 93 个声明的类型、原体和宇宙参数相同，其中四个声明的元数据有差异。

```sh
python3 Verification/no-island/graded-request-relay/certify.py --repo "$PWD" --compiled-root "$CP777_COMPILED_ROOT" --base-lean-path-file "$CP777_LEAN_PATH_FILE" --output "$CP777_AUDIT_DIR"
```

加 `--verify-inputs-only` 核对正式 Main 与冻结来源。
