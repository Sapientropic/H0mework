# 原出生收据的仿射写入与逆纤维

实际出生库存的每个有符号支持项沿原请求位置取得解码器、执行轨迹和有序库存段。由这些收据生成完整的有限支撑表及旧值、增量两支库存。原仿射归一将写入配对化为 `(-effect, effect)`，并给出所有产生同一写入的原像。

原 packet 等式把该写入送入字面下一包的关系 span。已有 siteAction 和 modelAction 将同一生成词写入随后库存。独立门检在原 Division 轨道上消费同次整账、规范后继及原 Riesz K。

四正一反及 46 个新逻辑声明通过严格复验，含 33 个私有声明。整数反控将旧值 1、增量 1 的开词归一为变量减常量 2，得到两支均非零的配对 `(-1, 1)`，合值为零。
