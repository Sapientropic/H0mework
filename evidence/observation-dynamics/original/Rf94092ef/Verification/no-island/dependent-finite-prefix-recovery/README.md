# 原观测有限前缀与实际后继恢复

原观测行归一化后生成有限 Gram 作用和驱动。第 $n$ 个有限作用与极限作用的算子范数差至多 $2^{-n}$，两次对应有限均值的差至多 $n2^{-n}‖x‖$。极限不动空间恰是全部原观测的共同核，有限程序恢复核的正交补。

既有 dependent `stageEvaluator` 与 `embedding` 消费当前恢复，原 `nextCoimage` 消费逐格移去第一槽后的观测。实际 Fock pulse 的同一原子 cotest 在下一格读到 $1/2$，原整账与收据保留。每个实际有限解码器至少保有 $1/4$ 的原时间损失，因此无法恢复为原过去值。
