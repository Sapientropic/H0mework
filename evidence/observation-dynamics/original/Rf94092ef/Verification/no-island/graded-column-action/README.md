# 原请求生成的分级列作用

原数学动作从已装材料选择实际环境增量。同一库存请求的位置、原值和效果生成完整列。四项 Gram 与实际右端进入原逆，保留整个核纤维和合成余量。

原 site 的实际下一 joint 经同发生转换接回 born 向量，读出动作生成的余量。原整账、规范后继和两份库存沿同一 site 消费。反控取同向旧值与效果各为 1，完整 Gram 为 4，删两交叉项只得 2。

四正一反和 41 个新逻辑声明通过严格复验，含 7 个私有声明。四个直接父项按 CP477 原签、冻结源码和同 inode 对象复用。

```sh
python3 Verification/no-island/graded-column-action/certify.py --repo "$PWD" --compiled-root "$CP776_COMPILED_ROOT" --base-lean-path-file "$CP776_LEAN_PATH_FILE" --output "$CP776_AUDIT_DIR"
```

加 `--verify-inputs-only` 核对正式 Main 与冻结来源。
