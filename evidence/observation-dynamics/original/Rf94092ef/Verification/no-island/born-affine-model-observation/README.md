# 原出生仿射词的模型读出

原停站材料给注册环境，原 PostDecoder 给同一停站的 active environment。二者认回原 nativeInventory 的旧值和增量。原 packet 等式把实付出生词送入字面下一站。原 Model 在该站读出 `(-effect, effect)`，decoder 合值为零。effect 非零时，同一 Model 类非零。

独立门检沿原 Division 的字面 packet 消费实际 span 和随后模型写入，并接原整账、规范后继及 Riesz K。整数反控把原仿射归一生成的变量减常量 2 送入已有完整观察历史。同一词在双支模型可见，在 decoder 合值模型为零。
